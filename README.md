# Rekrutacja IT-AI: Raptors PŁ 2026

Cześć! Tutaj znajdują się zadania rekrutacyjne do sekcji IT-AI koła Raptors. 

## Jak zacząć?
1. Kliknij przycisk **Fork** w prawym górnym rogu. Upewnij się, że opcja *Copy the simulation branch only* jest zaznaczona.
2. Sklonuj swojego forka na komputer: `git clone <link-do-twojego-forka>`
3. Utwórz branch ze swoimi danymi: `git checkout -b rekrutacja-imie-nazwisko`
4. Rozwiązania zadań (paczki ROS 2) umieszczaj w folderze `raptors_recruitment`.

## Zadania do wyboru (Etap 2 i 3)
*W tym miejscu wpiszesz konkretne zadania, o których rozmawialiśmy wcześniej (np. Prosty czujnik dystansu, Automatyczny "Stop" przed ścianą).*

## Jak oddać zadanie?
1. Zrób commita i wypchnij swój kod: `git push -u origin rekrutacja-imie-nazwisko`
2. Wejdź na stronę swojego forka na GitHubie i kliknij **New Pull Request**.
3. Skieruj Pull Request do oryginalnego repozytorium do brancha `simulation`.
